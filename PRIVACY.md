# MKonnect Privacy Policy

Last updated: September 17, 2026

MKonnect is a software project developed by Gameherit.

MKonnect uses Google Sign-In to authenticate users. The Google account information provided to MKonnect is used only to identify the user's account and provide the requested profile synchronization features.

MKonnect does not sell or share personal information with third parties.

User profile data is used only for the functionality provided by MKonnect.

The following informations are stored into a JSON file that can be read by authorized developers :

- Your Google account email
- Your Wiicompiled profile data (such as friend code, Mii id, VR and BR...)

This file **will never** be shared to anyone else.

For questions about this privacy policy, please contact the project owner through the MKonnect GitHub repository:

https://github.com/Gameherit/MKonnect
